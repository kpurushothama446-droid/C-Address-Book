# 📒 Address Book Management System in C

A menu-driven **Address Book Management System** developed using C programming. This project allows users to manage contact information through basic CRUD operations, with file handling for data storage.

## 🚀 Project Overview

The Address Book Management System is a command-line application that helps users store and manage contact details efficiently.

Users can add new contacts, search for existing contacts, modify contact information, delete contacts, and display all saved records.

## ✨ Key Features

- **Add Contact:** Store a contact's name, phone number, and email address.
- **Search Contact:** Find a contact using the available search logic.
- **Modify Contact:** Update existing contact information.
- **Delete Contact:** Remove a contact from the address book.
- **Display Contacts:** View all stored contacts.
- **File Handling:** Store and retrieve contact information using a CSV file.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| C Programming | Application development |
| Structures | Organizing contact details |
| File Handling | Persistent data storage |
| Pointers | Working with memory and data |
| CSV File | Storing contact records |

## ⚙️ How It Works

1. The program displays a menu of available operations.
2. The user selects an operation.
3. Contact details are managed using C structures.
4. File handling is used to save and retrieve contact records.
5. The program continues until the user chooses to exit.

## 💻 Compilation and Execution

Compile the program using GCC:

```bash
gcc main.c -o addressbook
```

Run the executable:

```bash
./addressbook
```

On Windows:

```bash
addressbook.exe
```

If your project contains multiple `.c` files, include all required source files in the compilation command.
